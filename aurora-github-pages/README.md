# Aurora Music — GitHub Pages

1. 在 GitHub 新建一个空仓库，例如 `aurora-music`。
2. 上传本文件夹中的全部文件和文件夹到仓库根目录。
3. 在仓库依次打开 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**、分支 `main`、文件夹 `/(root)`，然后点 **Save**。
5. 等待 Pages 发布完成，打开显示的网站地址，再用 iPhone Safari 选择“分享 → 添加到主屏幕”。

`app.html` 是应用本体；`index.html` 是可安装的 PWA 入口。请保持这些文件在同一目录。
